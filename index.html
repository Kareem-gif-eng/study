Task 2: Variables, Constants & Operators

1. المطلوب:
  • تعريف الثابت PASSING_GRADE بقيمة 50.
  • إنشاء متغيرين للأرقام وتنفيذ العمليات الحسابية الأساسية.
  • استخدام العمليات الشرطية والمعاملات المنطقية && لاختبار الشروط.
2. الكود البرمجي (Solution):
<?php
define("PASSING_GRADE", 50);

$num1 = 12;
$num2 = 4;

echo "Sum: " . ($num1 + $num2) . "\n";
echo "Difference: " . ($num1 - $num2) . "\n";
echo "Product: " . ($num1 * $num2) . "\n";
echo "Division: " . ($num1 / $num2) . "\n";

$studentGrade = 65;
$age = 20;

echo "Is Passing: " . ($studentGrade >= PASSING_GRADE ? "true" : "false") . "\n";
echo "Passing and Adult: " . (($studentGrade >= PASSING_GRADE && $age > 18) ? "true" : "false");
?>
3. النتيجة المخرجة (Output):
Sum: 16 Difference: 8 Product: 48 Division: 3 Is Passing: true Passing and Adult: true

الورشة 2: Control Flow & Logic Structures

Task 1: FizzBuzz Challenge

1. المطلوب:
  • إنشاء حلقة for للعد من 1 إلى 15.
  • طباعة Fizz لمضاعفات 3، وBuzz لمضاعفات 5، وFizzBuzz للمضاعفات المشتركة.
2. الكود البرمجي (Solution):
<?php
for ($i = 1; $i <= 15; $i++) {
    if ($i % 3 == 0 && $i % 5 == 0) {
        echo "FizzBuzz ";
    } elseif ($i % 3 == 0) {
        echo "Fizz ";
    } elseif ($i % 5 == 0) {
        echo "Buzz ";
    } else {
        echo $i . " ";
    }
}
?>
3. النتيجة المخرجة (Output):
1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz

Task 2: Grade Evaluation System

1. المطلوب:
  • تقييم الدرجة وحساب التقدير (A, B, C, D, F) عبر switch (true).
2. الكود البرمجي (Solution):
<?php
$score = 85;

switch (true) {
    case ($score >= 85 && $score <= 100):
        echo "Grade: A";
        break;
    case ($score >= 75):
        echo "Grade: B";
        break;
    case ($score >= 65):
        echo "Grade: C";
        break;
    case ($score >= 50):
        echo "Grade: D";
        break;
    default:
        echo "Grade: F";
}
?>
3. النتيجة المخرجة (Output):
Grade: A

Task 3: Calculator & Zero Division Guard

1. المطلوب:
  • بناء نظام حاسبة للعمليات مع منع خطأ القسمة على الصفر.
2. الكود البرمجي (Solution):
<?php
$a = 10;
$b = 0;
$operation = "/";

switch ($operation) {
    case "+": echo "Result: " . ($a + $b); break;
    case "-": echo "Result: " . ($a - $b); break;
    case "*": echo "Result: " . ($a * $b); break;
    case "/":
        if ($b == 0) {
            echo "Error: Division by zero!";
        } else {
            echo "Result: " . ($a / $b);
        }
        break;
    default: echo "Invalid operation";
}
?>
3. النتيجة المخرجة (Output):
Error: Division by zero!

الورشة 3: Functions & Array Processing

Task 1: Custom Functions & Arrow Functions

1. المطلوب:
  • دالة تنظيف وتنسيق النصوص، ودالة سهمية (fn()) لتسديد الخصومات وتقريب الناتج.
2. الكود البرمجي (Solution):
<?php
function formatName($name) {
    return strtoupper(trim($name));
}

$calculateDiscount = fn($price, $discount) => round($price - ($price * $discount), 2);

echo "Formatted Name: " . formatName("  ahmed mohamed  ") . "\n";
echo "Final Price: " . $calculateDiscount(199.99, 0.15);
?>
3. النتيجة المخرجة (Output):
Formatted Name: AHMED MOHAMED Final Price: 169.99

Task 2: Multidimensional Array Processing

1. المطلوب:
  • معالجة مصفوفة متداخلة للطلاب، حساب المتوسط، وتحديد صاحب أعلى درجة.
2. الكود البرمجي (Solution):
<?php
$students = [
    ["name" => "Ali", "grade" => 85],
    ["name" => "Sara", "grade" => 92],
    ["name" => "Mona", "grade" => 78]
];

$totalGrades = 0;
$highestStudent = "";
$maxGrade = -1;

foreach ($students as $student) {
    $totalGrades += $student['grade'];
    if ($student['grade'] > $maxGrade) {
        $maxGrade = $student['grade'];
        $highestStudent = $student['name'];
    }
}

$average = $totalGrades / count($students);

echo "Average Grade: " . round($average, 2) . "\n";
echo "Top Student: " . $highestStudent . " with " . $maxGrade;
?>
3. النتيجة المخرجة (Output):
Average Grade: 85 Top Student: Sara with 92

Task 3: Array Filtering Callback

1. المطلوب:
  • تصفية عناصر المصفوفات باستخدام array_filter ودوال المراجعة Callback.
2. الكود البرمجي (Solution):
<?php
$contacts = [
    ["name" => "Omar", "city" => "Cairo"],
    ["name" => "Hassan", "city" => "Alexandria"],
    ["name" => "Khaled", "city" => "Cairo"]
];

$cairoContacts = array_filter($contacts, function($contact) {
    return $contact['city'] === "Cairo";
});

print_r($cairoContacts);
?>
3. النتيجة المخرجة (Output):
Array ( [0] => Array ( [name] => Omar [city] => Cairo ) [2] => Array ( [name] => Khaled [city] => Cairo ) )

Task 2: Form Sanitization & Validation

1. المطلوب:
  • تطهير إدخالات المستخدم عبر htmlspecialchars واختبار صحة البريد الإلكتروني.
2. الكود البرمجي (Solution):
<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $username = htmlspecialchars(trim($_POST['username']));
    $email = filter_var($_POST['email'], FILTER_VALIDATE_EMAIL);

    if ($email) {
        echo "Valid User: " . $username . " (" . $email . ")";
    } else {
        echo "Invalid Email Address!";
    }
}
?>
3. النتيجة المخرجة (Output):
Valid User: Ahmed (ahmed@example.com)

Task 3: File Upload Validation

1. المطلوب:
  • فحص امتدادات ونوع وحجم الملفات عند رفعها لضمان الأمان.
2. الكود البرمجي (Solution):
<?php
if (isset($_FILES['avatar'])) {
    $fileTmp = $_FILES['avatar']['tmp_name'];
    $fileName = $_FILES['avatar']['name'];
    $fileSize = $_FILES['avatar']['size'];
    $allowedTypes = ['image/jpeg', 'image/png'];

    if (in_array($_FILES['avatar']['type'], $allowedTypes) && $fileSize <= 2000000) {
        move_uploaded_file($fileTmp, "uploads/" . $fileName);
        echo "File Uploaded Successfully!";
    } else {
        echo "Invalid File Format or Size!";
    }
}
?>
3. النتيجة المخرجة (Output):
File Uploaded Successfully!

Task 2: File Read/Write Operations (File I/O)

1. المطلوب:
  • كتابة وإلحاق وقراءة سجل العمليات داخل ملف نصي خارجي.
2. الكود البرمجي (Solution):
<?php
$filePath = "log.txt";
$logData = date("Y-m-d H:i:s") . " - User visited page\n";

file_put_contents($filePath, $logData, FILE_APPEND);

$content = file_get_contents($filePath);
echo "Logs Content:\n" . htmlspecialchars($content);
?>
3. النتيجة المخرجة (Output):
Logs Content: 2026-10-04 22:30:00 - User visited page
